## 4. Windows branch mechanics

One PowerShell script shipped as a FILE (`scp` explicit filename +
home-relative target — selfupdate lessons) and run via
`ssh host powershell -NoProfile -ExecutionPolicy Bypass -File fleetd-probe.ps1`,
emitting a tab-separated TOOL/HOST/WSL/DAEMON line protocol parsed in Rust
(`parse_windows_output`). No bash syntax touches Windows. The script probes
tools via Get-Command + per-tool version args (`go version` special-cased),
host facts via CIM, WSL via `wsl --status` exit code, docker/podman daemons
via `info --format '{{.ServerVersion}}'` (podman has the `version --format`
fallback). Best-effort `del fleetd-probe.ps1` cleanup.
